About

The short version

Alex Corrino is the name I build under. The pattern behind the projects is the same every time: find a question where the common answer feels underexamined, work through the numbers from first principles, and publish the result as a site anyone can read — no paywall, no newsletter gate.

The first of these is Memory Analyst, a standing analysis of AI memory demand versus what the world can actually manufacture. More are on the way.
