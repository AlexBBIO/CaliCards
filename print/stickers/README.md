# Holographic sticker artwork

Print-ready art for **Cali Coast Cards** holographic stickers.

## The card-trio set (the main event)

Built from the three-card CCC mark — each card is a different finish, and the
foil lands where it would on the real card:

| File | Cut / size | What's bare foil (shiny) |
| --- | --- | --- |
| `sticker-card-trio` | die-cut, ~3.6" × 2.16" | reverse-holo card **body** · classic-holo card **art window** · illustration rare **glint streaks** |
| `sticker-trio-banner` | die-cut, ~3.2" × 2.25" | same three + **twinkles in the wordmark banner** |
| `sticker-trio-badge` | rounded square, 3" × 3" | same three + **sparkles cut out of the navy tile** |

Every variant has a `-screen` twin with the holo simulated in pastel rainbow —
that's for posting digitally (Instagram, listings), **not** for printing.
Generated by `tools/build-stickers.js`, rendered by `tools/render-stickers.js`.

## How the holo effect works

Holographic stickers are printed on rainbow foil vinyl. The printer lays
**white ink under everything you want solid**; anywhere left **transparent**
stays bare foil and does the rainbow thing.

These files use *true transparency* (not white) for the foil areas, so they
work with any vendor. If the vendor asks, tell them:

> Transparent areas = **no white ink** (bare holographic material).
> Everything else gets a full white-ink underlay.

## Files

- **`*.png`** — upload these. ~400 dpi at the sizes above, with real alpha
  transparency for the foil areas and the die-cut background.
- **`*.svg`** — vector source. The banner/badge variants use the site fonts,
  so the PNGs are the reliable upload; regenerate them with the tools below.

## How to order (10 minutes)

1. **stickermule.com** → "Holographic die-cut stickers" (easiest; ~$60 list
   for 50 at 3", but they run frequent 40–50%-off deals — check the front
   page or wait a day for the email coupon). Alternatives: **stickerapp.com**
   (more foil patterns, similar price), **vograce.com** (way cheaper in bulk,
   the TCG-artist favorite, ~2–3 week shipping from overseas).
2. Upload the `*.png` (never the `-screen` version — that would print fake
   rainbow instead of using real foil).
3. Size: **3"** on the longest side is the sweet spot for handouts and
   package-outs; 2" if you want cheap package inserts.
4. Cut: **die-cut** for trio/banner (they follow the artwork outline;
   the vendor adds a thin material border that comes out rainbow chrome —
   looks great). The badge is a simple rounded square.
5. **Check the proof**: foil areas must show as shiny/foil, *not white*.
   If the proof shows them white, reply with the note quoted above.

npm i playwright            # local-only dep, not committed
