# Holographic sticker artwork

Print-ready art for **Cali Coast Cards** holographic die-cut stickers, built from
the CCC logo (`/icon.svg`). Three variants:

| File | Look |
| --- | --- |
| `sticker-holo-c` | Navy tile, gold + red C's printed, **middle C is bare rainbow foil** |
| `sticker-holo-ccc` | Navy tile, **all three C's in rainbow foil** |
| `sticker-holo-field` | **Whole tile is rainbow foil**, navy frame + gold/navy/red C's printed |

## How the holo effect works

Holographic stickers are printed on rainbow foil vinyl. The printer lays
**white ink under everything you want solid**; anywhere left **transparent**
stays bare foil and does the rainbow thing.

These files use *true transparency* (not white) for the foil areas, so they
work with any vendor. If the vendor asks, tell them:

> Transparent areas = **no white ink** (bare holographic material).
> Everything else gets a full white-ink underlay.

## Files

- **`*.png`** — upload these. 1200 × 1200 px = 400 dpi at 3" × 3", alpha
  transparency for the foil areas.
- **`*.svg`** — vector source, editable. Some vendors accept SVG directly.

## Ordering notes

- **Size:** 3" is a good handout/booth size; 2" for package inserts.
- **Cut:** die-cut, following the rounded square. The vendor adds a small
  material border around the art — on holo stock that rim comes out rainbow
  chrome, which looks great. No bleed needed for die-cut; their proof will
  confirm.
- **Finish:** glossy is standard for holo. Ask for the proof before approving —
  check that the transparent areas show as foil, not white.
- **Vendors:** Sticker Mule (easiest, fast US shipping, frequent deals),
  StickerApp (more foil pattern choices), Vograce (cheapest in bulk, popular
  with TCG artists, longer shipping).
